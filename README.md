## 🔧 Technical Stack

- **Backend**: Node.js, Python
- **NLP**: BERT, GPT, spaCy, NLTK
- **Databases**: PostgreSQL, MongoDB, Redis, Elasticsearch
- **Infrastructure**: Kubernetes, Docker, Terraform
- **Monitoring**: Prometheus, Grafana, ELK Stack
- **CI/CD**: GitHub Actions
